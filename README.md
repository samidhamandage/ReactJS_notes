👉Library
A library is a tool that provides specific features to a website/application.
Examples:
React.js → Build user interfaces (UI)
GSAP → Animations
Lenis → Smooth scrolling
 We use a library when we need a particular feature.

👉Framework
A framework provides a complete structure for building an application.
Examples:
Next.js
Angular

Library = You control the code.
Framework = Framework controls the structure.


👉Why do we use React?
React is used to make websites easily and interactively.
For example:
Change content without reloading the whole page
Create reusable parts like buttons, cards, navbar
Easily manage changing data
 In simple words: React helps us build and manage the UI of a website easily.

 👉Real DOM: The actual webpage structure that the browser displays and updates.
Virtual DOM: A lightweight copy of the DOM that React uses to update only the changed parts efficiently.
